Privacy Policy

Outreach Bot. Last updated 10 September 2026.

Scope

Outreach Bot is a personal tool with exactly one user: its author, Gaurav Rathore. It operates only on his own Google account, rathore.gaurav1007@gmail.com. No other person can sign in to it, and it collects no data from anyone else who installs or uses it, because nobody else does.

What data is accessed

With the owner's authorisation, the tool reads message metadata and message text from the owner's own Gmail mailbox: sender and recipient addresses, subject lines, dates and message bodies of threads he started. It creates draft messages in that same mailbox, and may move a draft it created to Trash if the recipient replies before the draft is sent.

What data is stored, and where

The tool keeps a small working record so it does not write to the same person twice: the email addresses the owner has already contacted, the associated company name, thread identifiers, dates, and the outcome of each run. This record is stored in a private repository belonging to the owner, on GitHub, and is visible only to him.

Message bodies are read during a run in order to decide what to do, and are not retained after that run finishes.

How data is used

Solely to decide whether one of the owner's own email threads still warrants a follow-up, and to draft that follow-up. There is no other purpose.

Sharing and sale of data

No data is sold, rented, or shared with third parties for advertising, marketing, profiling or any similar purpose. Data is not transferred to anyone except the infrastructure providers strictly required to run the tool: Google (the mailbox itself), GitHub (which executes the scheduled job and stores the working record), and Anthropic (whose API composes the draft text). Each processes the data only to provide that service.

Google user data is never used to train generalised or foundational artificial intelligence models.

Retention and deletion

The working record is retained while the tool is in use and can be deleted by its owner at any time by deleting the repository. Access can be withdrawn instantly at myaccount.google.com/permissions, after which the tool can no longer read or write anything.

Security

Credentials are held as encrypted repository secrets and are never written into logs, source code or stored files. Connections to Google are made over HTTPS.

Limited Use

Outreach Bot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy: rathore.gaurav1007@gmail.com
